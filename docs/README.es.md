# Documentación de Workspace

Cada documento operativo tiene una edición en inglés y otra en español. Si una
regla difiere de la implementación, prevalecen los esquemas versionados y las
pruebas; abre un issue para corregir la documentación.

Consulta el [índice bilingüe](README.md) para acceder a instalación,
arquitectura, privacidad, fuentes, DeepSeek, licencias, contratos, evaluación
y solución de problemas.

El repositorio no debe contener CV reales, archivos históricos de vacantes,
paquetes de candidatura, pesos de modelos ni modelos 3D de terceros. Todos los
ejemplos deben ser sintéticos.
