# Third-party assets

The Apache-2.0 license in this repository covers source code only.

The local project includes one unmodified, user-supplied GLB: **Smol Ame in an
Upcycled Terrarium** by Seafoam. Its embedded metadata identifies the original
Sketchfab page and the CC BY 4.0 license. Exact checksum, attribution, animation
duration, and provenance are recorded in `assets/manifest.json`. The asset is
not relicensed under Apache-2.0.

The application also includes a code-authored static SVG fallback. It contains
no geometry, textures, voices, or recordings from the GLB.

See `assets/manifest.json` and `docs/licensing.md` for the authoritative status
of each slot.
